MyTaxAssist Responsive Design Rules

Breakpoint Tokens

Device Width Rule
Desktop 1280px and above Use full 3-column layout.
Laptop 1024px - 1279px Keep sidebar. Reduce right panel width or make it collapsible.
Tablet 768px - 1023px Collapse right panel into drawer or below main content.
Mobile Below 768px Use single-column layout.

Main Layout Behaviour

Area Desktop Tablet Mobile
Left Sidebar Fixed width: 280px Collapsible drawer Hidden behind menu button
Main Chat Area Flexible center area Full width after sidebar collapse Full width single column
Right Document/Form Panel Fixed width: 340px Drawer or below chat Bottom sheet / full-screen panel
Top Header Height: 60px Height: 56px Height: 52px

Standard Media Queries

@media (max-width: 1279px) {
  /* Laptop adjustments */
}

@media (max-width: 1023px) {
  /* Tablet layout */
}

@media (max-width: 767px) {
  /* Mobile layout */
}

Form Responsiveness

Screen Size Form Layout
Desktop Use 2-column forms where space allows.
Tablet Use 1-column or compact 2-column layout.
Mobile Always use 1-column full-width inputs.

Chat Responsiveness

Element Desktop Mobile
Message Bubble Maximum width: 70% Maximum width: 88%
Chat Input Fixed at bottom of chat area Fixed at bottom, full width
Attachments Shown in right panel Shown in bottom sheet or document tab

Navigation Responsiveness

Screen Size Navigation Rule
Desktop Use persistent left sidebar.
Tablet Use collapsible sidebar.
Mobile Use hamburger menu or bottom navigation.

Agent Rules

  • Every screen HTML must include responsive media queries.
  • Use the same breakpoint values across all screens.
  • Do not create screen-specific breakpoints unless required.
  • Desktop designs should follow the full application layout.
  • Mobile designs should prioritize chat, forms, and document upload actions.
  • Right-side panels should never remain squeezed on mobile.
